# CyberCloud-Lab v2

A hybrid security monitoring lab. Honeypot sensors in AWS capture real attack
traffic, and a home server runs Splunk and a custom dashboard to detect and
investigate it.

**Status:** rebuild in progress. This is a from-scratch redo of my first
CyberCloud-Lab project.

## Goals for v2

- Understand the MITRE ATT&CK framework well enough to write and test my own detections.
- Learn how a hybrid cloud and on-premises environment is monitored end to end.
- Document every finding properly, with evidence.
- Build a better monitoring dashboard than the first version had.
